# 🎹 Pianist Assistant

钢琴练习助手：上传 MusicXML 琴谱，全屏显示并播放，播放时光标跟随，可调速、分左右手、分声部（四手联弹）、循环练习。

- 网页：GitHub Pages，推送到 `main` 后自动部署，**不需要手动启动**，可“安装”到手机/电脑桌面（PWA）。
- 琴谱：存放在**另一个私有仓库**（例如 `PianistScores` 的 `scores/` 目录），本仓库只有代码。
- 登录：用只授权该私有仓库的 GitHub 令牌。没有令牌看不到任何琴谱。

## 一次性设置（约 5 分钟）

1. **建私有仓库**：GitHub 新建 `PianistScores`，选 **Private**（里面放什么都可以，应用会自动创建 `scores/` 目录）。
2. **开启网页部署**：本仓库 Settings → Pages → Source 选 **GitHub Actions**；把开发分支合并到 `main`，等 Actions 里的 `deploy` 跑完。网址：`https://user202201.github.io/PianistAssistant/`
3. **生成令牌**：https://github.com/settings/personal-access-tokens/new
   - Repository access：**Only select repositories** → 只选 `PianistScores`
   - Permissions → Repository permissions → **Contents: Read and write**
   - Expiration：最长 1 年，到期后重新生成一个即可
4. 打开网址，粘贴令牌登录。每台设备登录一次，之后自动记住（只保存在该设备浏览器里）。

## 多设备登录

- **扫码登录**：在已登录的设备上，设置 ⚙ → 登录与设备 → 手机扫码登录，用另一台设备的相机扫描即可，二维码 60 秒后自动关闭。也可以“复制登录链接”粘贴到新设备的登录页。
- **保持登录**：登录页默认勾选。不勾选则关闭页面后需重新登录，适合公用设备。
- **iPad / iPhone**：请先用 Safari“添加到主屏幕”，再从主屏幕图标打开并登录。Safari 对长期不用的网页会清除记住的登录，装到主屏幕的应用不会。主屏幕应用的存储和 Safari 是分开的，所以要在主屏幕应用里登录（用“复制登录链接”粘贴最方便）。
- 所有设备共用同一个令牌，**无法单独移除某台设备**。设备丢失时到 GitHub 令牌管理删除令牌，所有设备立即失效，再生成新令牌即可。

## 安全说明

| 问题 | 情况 |
|---|---|
| 别人改我的代码 | 只有你的 GitHub 账号能推送本仓库；建议开启两步验证，并给 `main` 开分支保护。 |
| 别人看我的琴谱 | 琴谱在私有仓库，读取必须带令牌。登录时若检测到仓库是公开的会拒绝登录。 |
| 令牌泄露 | 令牌只能访问那一个私有仓库，且可在 GitHub 随时撤销。不要把令牌发给别人或写进代码。 |
| 网页代码是公开的 | 是，但里面没有任何秘密，也不含琴谱。 |

## PDF / 照片自动转换（一次性设置）

上传 PDF 或照片后，会先放进私有仓库的 `inbox/`，由私有仓库里的 GitHub 自动任务调用开源乐谱识别软件 [Audiveris](https://github.com/Audiveris/audiveris) 转成 MusicXML，存到 `scores/`，几分钟后出现在琴谱列表里。失败时主页会显示“转换失败”和原因。

**设置：在私有仓库 `PianistScores` 里添加一个文件**（令牌没有修改工作流的权限，所以只能手动加一次）：
1. 打开 PianistScores → Add file → Create new file
2. 文件名填 `.github/workflows/convert.yml`
3. 内容复制本仓库 [`scores-repo-template/.github/workflows/convert.yml`](scores-repo-template/.github/workflows/convert.yml)（很短，只负责调用本仓库里的 `scores-repo-template/convert.sh`，所以以后改进转换逻辑不需要再改这个文件）
4. Commit changes

转换失败时，主页的失败卡片点 ℹ 能看到原因；修好后点 🗑 删除失败项，再重新上传即可。

注意：
- 识别准确率有限。清晰的印刷谱较好，照片、手写、复杂钢琴谱会有错音和错时值，**转换后务必打开核对**。
- 私有仓库使用 GitHub Actions 有每月免费额度（个人账号 2000 分钟），一份谱子通常几分钟。
- 多乐章的 PDF 目前只取第一个乐章。

## 指法

每个音符的指法按这个顺序取：
1. **乐谱 XML 里已有的指法**（黑色，直接显示）
2. **自动建议指法**（蓝色，仅作参考）：按手型和音程的规则计算，音阶和简单旋律较可靠，复杂乐句请以老师为准。已有指法的音符不会被改动。
3. **自己标注**：控制栏“指法 → 编辑指法”，点音符再点数字 1-5（也可用外接键盘），点“保存”后写进乐谱的 XML 文件。之后读取时就是第 1 种来源，所以老师标好的指法会一直保留。

说明：目前没有“按曲目联网查询指法”的公开数据库或接口，所以第 2 步使用内置的规则算法。

## iPad

- 先用 Safari“添加到主屏幕”，再从桌面图标打开使用（全屏、不会被清除登录）。
- iPad 默认放大乐谱；按钮按触屏大小设计，横屏时控制栏压缩成一行。
- 首次播放需要点一下播放按钮（iOS 要求用户操作才允许出声）。**如果没声音，请检查 iPad 侧边的静音开关/控制中心的静音**，应用已尽量让声音不受静音开关影响。
- 应用切到后台会自动暂停（iOS 会挂起声音），回来后点播放继续。
- 拍乐谱照片：上传时选“拍照”即可。

## 支持的琴谱格式

`.musicxml` / `.xml` / `.mxl`（MuseScore、Finale、Sibelius、Dorico 都能导出）。`.mxl` 上传时会自动解压成普通 `.musicxml` 保存，方便以后编辑。
PDF / 图片见上面的自动转换。MIDI 以后可加。

## 功能

- 播放 / 暂停 / 回到开头，空格键暂停，←→ 切换小节；速度 20%–150%
- 左右手选择（双手 / 右手 / 左手）
- 声部选择：多个声部（如四手联弹 Primo / Secondo）可单独开关声音，用来和自己合奏
- 练习：开始前倒数、节拍器、循环指定小节、每遍循环自动加速
- 钢琴音色可切换（设置 ⚙）：Splendid / FluidR3 / MusyngKite / 明亮钢琴 / 电钢琴；音色下载失败时自动用内置合成音色
- 重复记号、连音线、速度变化均会按乐谱处理；光标自动跟随并滚动
- **表情演奏**：按乐谱里的力度（pp–ff、sf）、渐强渐弱、重音、断奏、连奏、踏板演奏；没有记号时也有强弱拍和旋律层次。练习面板里可以关掉，所有音用同样力度。
- **四手联弹（分屏）**：多声部谱子默认上下分屏，A 声部一屏、B 声部一屏，每屏各有自己的声音开关、右手、左手；底部操作栏可收起成只剩共用的播放键；每个声部可以“全屏”，另一个声部继续发声。一个人练 A 时关掉 A 的声音，就能听到 B 的配合。设置里可以关闭分屏（改为上下叠在一起，仍可分别选 A/B 和左右手）。试听文件：`samples/Four-Hands-Duet.musicxml`。分屏模式里暂不提供指法编辑。
- **四手联弹分开上传**：A、B 两个人的谱子是两个文件时，主页会根据文件名里的 Primo/Secondo、A/B、1/2、Part 1/2、上/下 提示“像是四手联弹的两个声部”，点“合成四手联弹”才生效（不会自动合并）；也可以在卡片的 ⋯ 菜单里“设为四手联弹…”手动选择，或一次选两个文件上传时直接询问。合成后列表里是一张带“四手”标签的卡片，分屏打开；可交换 A/B、修改、取消关联。关联信息保存在私有仓库的 `config/pairs.json`，换设备也在。
- **提前预览下一行**：整屏翻页模式下，当前行下面放不下下一行时，在下方浮出下一行的预览（翻页后消失；预览只画乐谱，不含指法数字）。设置里可关闭。
- **外观**：设置里可选跟随系统 / 浅色 / 深色。
- **点击谱面选择从哪里开始播放**：点任意位置，光标跳到那里；播放中点击则从新位置继续。
- **画面跟随**（设置里选）：整屏翻页（默认，画面不动、换行时一次翻到位，不晕）/ 平滑滚动 / 不滚动；可高亮正在弹的这一行。
- **界面**：iPadOS 风格，浅色/深色自动跟随系统。
- **iPad 上刷新**：主页下拉刷新；主页和乐谱页右上角 ↻；设置里“检查更新”和“强制刷新（清除缓存，不会退出登录）”。检测到新版本时自动更新（播放中、编辑中不打断，会提示）；主页 ↻ 和设置里“检查更新”可手动触发，设置里能看到版本号

`samples/` 里有两份测试谱可以用来试用。

## 已知限制 / 后续可做

- 学习模式的“等待模式”（你弹对才往下走，需 MIDI 键盘）、点击乐谱跳转、MIDI 文件导入还没做。
- 表情演奏目前不处理渐慢（rit.）、延长号、弹性速度，这些需要文字识别或人工判断。
- 只能按乐谱文件里**已有**的记号演奏；PDF 转换常会丢失力度和速度记号。
- 节拍器按首个小节的拍号与速度固定节奏。
- 钢琴采样从公开 CDN 下载，首次加载后由浏览器缓存。
