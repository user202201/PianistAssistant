# Real PDFs for the engine comparison -- PUBLIC DOMAIN ONLY

This repository is **public**: everything committed here (and everything in its git history, and the results of the runs) can be read and copied by anybody.
Never put a PDF here unless you are sure it may be republished (public domain edition, your own engraving, a licence that allows it).

For PDFs of unknown or doubtful copyright use the private way: put them into the `lab/` folder of your own PRIVATE scores repository and run its `lab` workflow
(`scores-repo-template/.github/workflows/lab.yml`): the comparison runs there, the table stays in your private run, and the PDFs are deleted again afterwards
(and at the latest two days later). Only the table (numbers, no music) needs to be shown to anybody.
