**隐藏的游戏模式（彩蛋）**
- 连续点左上角音符 10 次开启（第 5 次抖动、第 10 次闪光、第一次有“隐藏模式已解锁”和烟花），再点一次可关闭（带确认，防连点冷却）。
- 开启后：左上角图标变发光音符，顶栏向下发蓝光，乐谱页顶部多一个“练习 / 游戏”开关。
- 游戏视图：荧光蓝主题；下方键盘 + 下落音符（长度按乐谱写的时值，延音用淡色表示）；可拖高度；平面 / 3D 透视切换（音符从面板最顶端落下，已调清晰）。
- 开始：READY → GO!（合成音效，没有语音）；开始前画面是空的。
- 四手联弹：被关闭的声部才是你要弹的；游戏视图里声部栏变成圆形玻璃图标按钮，A/B 按钮循环：全部 → 单独 A → 单独 B → 全部；游戏面板不会挤占谱子（每个声部至少留一整行）。
- 计分：演示 / 计分切换；判定 Perfect / Good / Early / Late / Miss / 错键；连击、分数；结束后弹出总结（星级、准确率、最长连击等）；演示模式有一个“完美的假玩家”，设置里可加失误来看特效。
- 输入：MIDI 钢琴（浏览器 Web MIDI；iOS App 里有原生 CoreMIDI 插件和蓝牙配对）、麦克风（听真钢琴，只听“该弹的音”）。
- 效果：判定文字 + 连击大横幅合成一个开关；延迟补偿（藏在卡片底部的下拉把手后面）。
