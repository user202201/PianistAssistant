Pianist Assistant — Privacy Policy

Last updated: 2026-11-09

In short: the app does not collect, store on a server, share or sell any personal data. It has no accounts, no analytics, no advertising and no third-party tracking.

Your sheet music

The scores, PDFs, favourites and settings you add stay on your device. The developer has no server and cannot see them. Deleting the app (or its data) deletes them — use the in-app backup to keep a copy.

Network use

  • The default piano sound is inside the app. Some optional piano sounds are downloaded from public servers of open-source sound libraries; like any download, the server sees your IP address.
  • The web version can optionally sync your library with your own GitHub repository using an access token that you create. The token stays on your device and is only sent to GitHub.
  • If you connect GitHub and upload a PDF for conversion, the file is stored in the GitHub repository you chose and is processed on GitHub's cloud machines (GitHub Actions) of that repository. The developer does not see these files. The store versions keep everything on the device; only if you yourself connect your own GitHub account under Settings → PDF conversion, a PDF that you choose to convert is put temporarily into your own private repository and deleted from it again after the result has come back to your device (it remains in that repository's git history).

Help & feedback

The feedback form opens your own mail app with a prepared message; nothing is sent until you press send in your mail app. The message contains what you typed plus the app version, system and language. It never contains your scores.

Children

The app collects no data from anybody, including children.

Pianist Assistant 隐私政策

最后更新：2026-11-09

简单说：本 App 不收集、不上传到服务器、不分享、不出售任何个人数据。没有账号，没有统计分析，没有广告，没有第三方跟踪。

你的乐谱

你添加的乐谱、PDF、收藏和设置都只保存在你的设备上。开发者没有服务器，看不到这些内容。删除 App（或它的数据）就会删除它们，请用 App 内的“备份”功能保存一份。

网络使用

  • 默认的钢琴音色已经包含在 App 里。部分可选音色会从开源音色库的公开服务器下载；和任何下载一样，对方服务器能看到你的 IP 地址。
  • 网页版可以选择用你自己的 GitHub 仓库同步乐谱，使用你自己创建的访问令牌。令牌只保存在你的设备上，只发送给 GitHub。
  • 连接 GitHub 后上传 PDF 转换时，文件会存到你自己指定的 GitHub 仓库，并在该仓库的 GitHub 云端机器（GitHub Actions）上处理；开发者看不到这些文件。商店版的所有内容都保存在设备上；只有你自己在“设置 → PDF 转换”里连接了自己的 GitHub 账号，你选择转换的 PDF 才会临时放进你自己的私有仓库，结果回到设备后从仓库里删除（仓库的 git 历史里仍会留有记录）。

帮助与反馈

反馈功能会打开你自己的邮件应用，并预先写好邮件；在你的邮件应用里点发送之前，什么都不会发出。邮件内容是你填写的内容，加上 App 版本、系统和语言，不包含你的乐谱。

儿童

本 App 不收集任何人的数据，包括儿童。

Pianist Assistant — Politique de confidentialité

Dernière mise à jour : 2026-11-09

En bref : l'application ne collecte, ne stocke sur aucun serveur, ne partage et ne vend aucune donnée personnelle. Pas de compte, pas de statistiques, pas de publicité, pas de suivi par des tiers.

Vos partitions

Les partitions, PDF, favoris et réglages que vous ajoutez restent sur votre appareil. Le développeur n'a pas de serveur et ne peut pas les voir. Supprimer l'application (ou ses données) les supprime — utilisez la sauvegarde intégrée pour en garder une copie.

Utilisation du réseau

  • Le son de piano par défaut est inclus dans l'application. Certains sons optionnels sont téléchargés depuis des serveurs publics de bibliothèques libres ; comme pour tout téléchargement, le serveur voit votre adresse IP.
  • La version web peut, en option, synchroniser votre bibliothèque avec votre propre dépôt GitHub grâce à un jeton que vous créez. Le jeton reste sur votre appareil et n'est envoyé qu'à GitHub.
  • Si vous connectez GitHub et envoyez un PDF à convertir, le fichier est stocké dans le dépôt GitHub que vous avez choisi et traité sur les machines cloud de GitHub (GitHub Actions) de ce dépôt. Le développeur ne voit pas ces fichiers. Les versions des stores gardent tout sur l'appareil ; seulement si vous connectez vous-même votre propre compte GitHub dans Réglages → Conversion de PDF, un PDF que vous choisissez de convertir est placé temporairement dans votre propre dépôt privé, puis supprimé une fois le résultat revenu sur votre appareil (il reste dans l'historique git de ce dépôt).

Aide et commentaires

Le formulaire ouvre votre propre application de messagerie avec un message prérempli ; rien n'est envoyé tant que vous n'appuyez pas sur envoyer. Le message contient ce que vous avez écrit, la version de l'application, le système et la langue — jamais vos partitions.

Enfants

L'application ne collecte de données auprès de personne, y compris les enfants.
